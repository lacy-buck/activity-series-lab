# Activity Series Lab

this will be for high school students who need to practice analyzing data of fictitious metals to create an activity series. Then answer questions based on this. I have uploaded the test that they will be taking. Don't give them the same data, but build something that has them practicing this concept. Make this into an experiment where they are actually collecting the data, recording it in a data table that they can access throughout the activity.  Have them create an activity series but the catch is that one of the substances they have to put in the table, they only have the data for how it acted as a solution, not as a metal.  Then after they have that set, give them one more metal to go in, but only give them limited data about it to help them place it.  After they have done that, ask them questions to help them explain what is going on with electrons if the reaction occurs.
